**Looked at and decided fine**

- `IST = timezone(timedelta(hours=5, minutes=30))`: correct; India has no DST, so a fixed offset is right.
- `load_dotenv()`: by default it does **not** override variables already in the environment, so "real env wins" already held (I made it explicit with `override=False`).
- Storing `date`, `joined_on` and shift times as strings: intended by the data model. `YYYY-MM-DD` and `HH:MM` sort correctly as text, which the code relies on for ranges and the overnight check.
- The helpers were worth keeping as pure functions, but not as they were: they now take the attendance date and employee, so R1 is applied in one place.
